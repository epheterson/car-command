{# What a page with a map loads: Leaflet for the map and its overlays, MapLibre (through its Leaflet binding) to draw the vector base, and the shared helpers. Every file is vendored under static/vendor (same versions as before: Leaflet 1.9.4, MapLibre GL 5.24.0, its Leaflet binding 0.1.4, licences beside them), so no page asks a CDN for anything. The scripts are deferred, so the page paints first; they run in order before DOMContentLoaded, which is when each page's own map script starts. Include it only when the page draws a map. #}
