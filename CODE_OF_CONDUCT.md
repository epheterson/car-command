# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Be kind, assume good faith, keep it about the work.

Report unacceptable behaviour privately through GitHub's [private reporting](https://github.com/epheterson/car-command/security/advisories/new) form, with "conduct" in the title. Reports are kept confidential and handled as the Covenant's enforcement guidelines describe.
